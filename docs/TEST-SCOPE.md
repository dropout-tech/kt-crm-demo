# 合成定位與報價測試版

2026/10/18。這是可操作的靜態合成示範，資料僅存在目前瀏覽器。沒有後端、正式登入或伺服器授權。

## 定位

現場拜訪記事可試成功、拒絕、逾時、不支援四種情境。成功使用固定合成座標與精度，保存測試時間；失敗沒有座標。程式不呼叫裝置定位、不請求位置權限。更換客戶／聯繫方式清除未保存定位，並允許未定位或失敗記事保存，這是示範假設，正式提交規則待確認。

## 報價

1. 示範業務由案件或工作台建立測試草稿；至少一個品項，最多 50。
2. 數量、測試單價及小計以十進位字串／BigInt 計算，避免浮點誤差；每列四捨五入至小數二位後加總，未計稅額。此計價只供流程測試，未代表公司制度。
3. 草稿建立人確認目前版本，送示範主管審核；退回需原因。
4. 目前版本核准才可下載測試 PDF。修改建立新版本，舊版快照與操作紀錄保留；業務確認／主管核准取消，需再確認與核准。
5. 每頁 PDF 有「測試樣張／範本待確認／不可對外正式報價」及品牌原圖。採 canvas 影像 PDF，中文可呈現，非可搜尋文字範本；原報價仍能編輯。

上述建立人與主管規則僅為本機測試情境，角色可切換，localStorage 可改動，**不是授權邊界或正式三層權限完成**。正式帳號、伺服器檢查、授權範圍與不可竄改稽核仍需實作。管理者示範帳號尚未加入，不能以現有兩類視角代表三層已完成。

## 已驗證與未驗證

- 已驗證模型、儲存相容、錯誤不部分寫入、不同企業關聯、精確金額、舊核准失效及 PDF 二進位結構。
- 桌機 Chrome 與 320／390／768／1024／1440px 畫面：合成定位四情境、角色流程、退回重送、多頁 PDF、下載、重開保存與版型；測試攔截真實定位呼叫，結果為零；沒有外部 API 請求。
- 以 Poppler 讀取與渲染一頁及六頁 PDF，視覺核對原始品牌、中文、浮水印、金額與頁碼。
- 尚未驗證實體 iPhone／Android、Safari、真實定位權限及手動 LINE 分享，不能將 viewport 測試當成實機驗證。
- 正式報價範本、品項／價格／稅額規則、正式帳號與權限矩陣、共享後端及 ERP／庫存均未由示範補足。
